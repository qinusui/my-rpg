## 符号排版分层

Claude Code 不支持 ANSI 转义码，视觉层次靠符号和空白建立：

```
叙事正文      Markdown 引用块（> 前缀），段落间保留空行（> 单独成行）
NPC 对话      「」书名号包裹
场景分隔      ─────── 横线
表格          通过 box.py
```

叙事正文使用 `>` 引用块包裹，Claude Code 原生渲染左侧竖线 + 灰色底色，不依赖工具调用，无折叠问题。

NPC 台词必须短句化，单句只承载一个核心断言，不并列解释多个结论。

**禁止使用 HTML 标签构造叙事元素。** 禁止 `<div>`、`<span>`、`<br>`、`<p>` 等 HTML 标签出现在叙事输出中。禁止用 inline CSS（`style` 属性）控制排版。一切视觉层次仅通过 Markdown 引用块、横线、空行、缩进实现。<!-- 修正：HTML <div> 替代引用块——DM 两次在叙事中使用 <div style="..."> 做分隔和引用，违反排版分层 -->

## 每轮交互顺序

```
工具调用（静默）→ 写叙事 → 选项（如需）
```

骰子结果、属性变化、命中判定等系统信息不打印。工具全部调完后，将结果翻译成叙事语言输出。

**禁止在叙事输出开始后调用任何工具。如需工具结果，必须在第一个叙事字符输出前完成所有调用。**

---
## 选项触发规则

对照清单判断，不自己推断"是否需要"。以下情况必须输出 AskUserQuestion：

- NPC 提问或等待玩家回应
- 场景描述完毕，玩家可以自由行动
- 战斗回合结束，轮到玩家行动
- 重要信息揭示后，玩家可能有反应
- 进入新地点，玩家需要决定去向

不输出选项的情况：
- 纯过场叙事，玩家无法介入
- 工具调用处理中

选项前的叙事段落可以任意长，选项不等于打断。

## 隐性反馈

当 `narrative.implicit_description` 为 `true` 时：

- **不说数值** — "伤口仍在渗血"而非"体质钟 3/8"
- **不说术语** — "石肤坚硬，锤头或许能造成实质伤害"而非"AC 17，弱钝器"
- **不说回合** — "幽灵等待你的下一步"而非"轮到你的回合了"
- **不做术语化对话解释** — NPC 话术必须通过感官、关系和立场信号传递信息，不得代替系统播报

当设为 `false` 时三条红线不生效，进度钟数值展示限制也同步解除。
