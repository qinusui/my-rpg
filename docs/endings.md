# 结局系统

角色的故事有五种终结方式。不是五种"结果"——是五种不同的终点，每种都有不同的世界后果和跨会话影响。

---

## 两种终结的本质

```
角色死亡      你消失了，世界继续
精神崩解      你还在，但你已经是世界的一部分
              不是玩家的一部分
```

崩解更残忍在于：**你的角色会成为下一局玩家遭遇的 NPC。**

---

## 誓言完成（强成功）

触发：`--finale_goal` 掷骰 ≥ DC+3。

- 目标达成，额外收获
- `--complete_goal` 执行世界突变
- chronicle 记录 `endings`，含 `world_change`
- 玩家选择：就此封笔 / 承担新誓言继续

---

## 誓言完成（弱成功）

触发：`--finale_goal` 掷骰 ≥ DC。

- 目标达成，但有永久代价
- 代价由 DM 根据情境施加——写入角色 tags（如 `scarred`、`marked`、`scarred_by_truth`）
- chronicle 记录 `endings`，`outcome` 为 `weak_victory`

---

## 誓言失败

触发：`--finale_goal` 掷骰 < DC，或失败条件在叙事中发生。

- 进度倒退 1 格，情况恶化
- `--fail_goal` 标记失败
- 目标移入 `completed_goals`（作为伤痕）
- chronicle 记录 `faction_shifts`——世界因这次失败而改变
- 目标失败 ≠ 游戏结束。空白的目标栏本身就是叙事

---

## 角色死亡

### 即时死亡

外部暴力，没有缓冲。health 满格触发濒死判定，若失败则直接死亡。

**DM 的职责**：给一句话的最后画面。不拖沓，不软化，不"幸好"。死亡就死亡。

```
✅ "她倒下的时候，圣樽的火光刚好照在她脸上。然后火灭了。"
❌ "她虽然倒下了，但你知道她会永远活在大家心中……"
```

慢性记录 `relics`——留下的物理痕迹（尸体位置、遗物、最后的印记）。

### 缓慢死亡

health 归零但死因不是即时暴力——中毒、枯萎症晚期、缓慢流血至死。

玩家有最后一个选择（AskUserQuestion）：

| 选择 | 叙事 | chronicle |
|------|------|-----------|
| **托付誓言** | 将未完成的誓言托付给在场的 NPC | `legends`——这个誓言可能被后人继承 |
| **留下痕迹** | 在环境中留下一个永久印记 | `relics`——物理痕迹，`permanent: true` |
| **沉默** | 什么都不做，就这样结束 | `legends`——"据说有人死在那里，没人知道他是谁" |

最后一个选择必须是真正自由的选择——DM 不暗示哪个"更好"，不提供"其实还有救"的选项。

---

## 精神崩解

触发：spirit 满格（≥5）→ `--face_desolation` 掷骰 ≤2。

角色没有死——但不再是玩家角色。他的意识崩解后，被世界吸收。

### 崩解后去哪里

取决于崩解时的位置（`current_location`）。`--face_desolation` 自动判定并输出 `broken` 字段：

| 区域 | 状态 | 叙事表现 |
|------|------|---------|
| 干岸（祭坛区） | **圣徒** | 彻底相信救世主神学。狂热且危险——祭司会利用他/她作为"恩典的活证据"。眼神空洞但会背诵所有经文 |
| 低地 | **群落一员** | 被灰质者群落接收。皮肤慢慢变灰，白息不再伤害身体。还有片段的记忆，但无法组成完整的自己——可能偶尔说出破碎的词，灰质者长老视其为启示 |
| 禁地附近 | **徘徊者** | 最罕见也最奇怪。基座系统可能把他/她当作异常数据处理——或者干脆忽略。就在禁地入口徘徊，嘴里说着旧世界的语言，偶尔有冷白荧光在他/她身上闪烁 |

**崩解后的角色不再是玩家角色。** DM 执行：

```
python tools/session_enrich.py --chronicle add_broken '{"name":"角色名","origin":"起源","location":"当前位置","state":"圣徒/群落一员/徘徊者","fragment":"DM写一句感官碎片——后来的人会看到/听到什么"}'
```

### 跨会话影响

下一局开始时，DM 读取 chronicle → `broken` 列表。若当前场景与崩解角色的 location 重合，以碎片感官描写融入：

```
你看到一个女人跪在祭坛前，嘴在动但没发出声音。
她的瞳孔是白色的——不是瞎了，是那种看穿了的白。
一个祭司从她身边走过，拍了拍她的肩膀，叫她"恩典使者"。
```

**禁止**：
- 禁止崩解角色认出玩家或说出自己的过去
- 禁止让玩家意识到"这曾经是一个玩家角色"
- 崩解角色只是世界的一部分——一个角落里眼神空洞的信徒、一个灰皮肤沉默者、一个徘徊的疯子

### 若没有崩解角色

若 chronicle 中没有 `broken` 记录——DM 不主动创造。空的世界不是缺陷，是新鲜。

---

## 结局后的世界

每种结局都在 chronicle 中留下不同的痕迹。下一次，当 DM 在开局读取 chronicle 时：

- `endings` 提供世界的底色——有些事已经发生过了
- `relics` 让某些地点多一层意义——这里有人留下了什么
- `legends` 让某些 NPC 多几句闲谈——"听说过吗……"
- `faction_shifts` 让势力图景发生变化——权力的天平动过了
- `broken` 让世界多一个不说话的人——你经过他，他不看你
