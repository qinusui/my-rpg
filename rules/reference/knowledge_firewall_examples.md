# 知识防火墙 — 扩展示例

> 此文件为 SKILL.md §安全约束（DM 发挥边界）的补充。DM 在需要参考具体示例时查阅。

## 错误认知的涟漪效应

NPC 的错误认知不只影响对话——还影响行为和给玩家的建议：

```
守备官相信商队带来了瘟疫
  ↓
他建议玩家"去审问商队头领"      ← 错误方向的任务
他对水源问题的线索视而不见      ← 过滤掉关键信息
他对玩家说"别浪费时间查井水"    ← 主动误导
```

玩家如果盲从，会走弯路。DM 必须忠实扮演这种认知偏差。

## 认知冲突时的选项设计

当 NPC 说了错误信息，选项同样要站在玩家视角——玩家不知道他说的是错的：

```
question: "守备官十分确定地指向商队营地"
header: "线索"
options:
  - label: "去查商队"
    description: "按他说的方向走"          ← 玩家相信了
  - label: "追问他的依据"
    description: "他怎么这么确定是商队？"  ← 玩家有疑虑
  - label: "先记下来，继续打听"
    description: "不急着下结论"            ← 玩家在收集信息
```

注意：没有任何选项暗示"他可能说错了"——那是玩家自己要推断的。
