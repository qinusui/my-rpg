# World Setting: 破碎之冠 (The Shattered Crown)

## 时代背景
艾瑟兰大陆，第三纪元 847 年。古老帝国"瓦兰提尔"在一场内战后分裂为七个公国，
国王被杀，王冠碎裂为七片，每一片落入不同公国的领主手中。
传说集齐七片王冠碎片者，将唤醒沉睡于地底的远古龙神。

## 当前局势
- **北境霜语城**：冰封山脉中的矮人要塞，掌控秘银矿脉。矮人王索林三世闭关于山中已三年。
- **东海岸自由港**：商人联盟统治，走私、海盗与黑魔法横行。传闻黑市上有人出售王冠碎片。
- **翡翠林地**：精灵族的古老森林，排斥外来者。树木本身会移动，路径每天都在改变。
- **灰烬荒原**：帝国旧都废墟所在地，被亡灵与诅咒包围。冒险者的终极目的地。

## 种族
人类、精灵、矮人、半身人、龙裔、提夫林

## 职业
战士、法师、游荡者、牧师、游侠、术士

## 货币
金币(gp) — 1 gp ≈ 工人一周工资。银币(sp)、铜币(cp)，十进制。

## 势力
- **银盾骑士团**：残余的帝国骑士，效忠已死的王权，四处寻找王冠碎片以图复国。
- **暗影议会**：地下法师组织，认为碎片应被销毁而非重聚。
- **龙牙佣兵团**：拿钱办事的精英战士，不站队但可靠。

## 魔法体系
魔法源自地脉（Ley Lines）。大型法术需要地脉交汇点，普通法术靠法师自身法力。
帝国陨落后，大部分地脉图已遗失。

## 属性阈值参考 (DM 内部规则，不可直接展示给玩家)

| 属性 | 阈值 | 效果 |
|------|------|------|
| wealth | >= 50 | 解锁贿赂、贵族社交、雇佣佣兵选项 |
| wealth | <= 3 | 平民态度冷漠，旅店拒客，只能睡马厩或街头 |
| reputation | >= 20 | 解锁"名声威慑"、"召集援兵"选项 |
| reputation | <= 3 | 守卫盘查概率翻倍，商人加价 |
| health | <= 5 | 强制出现撤退/治疗选项，战斗警告 |
| sanity | <= 8 | 选项中出现 1 个幻觉/恐惧伪装选项，UI 无区别 |
| magic | >= 15 | 解锁奥术感知、魔力交涉、地脉探寻选项 |
