# 誓言

以下四个为**固定池**。每次誓言选择时，DM 从中随机抽 1 个，再即兴原创 2 个，合计 3 个作为 AskUserQuestion 选项——不标明哪个是固定的。

玩家选定后不可更改。DM 执行 `--set_goal "誓言名"`，然后让玩家用自己的话宣告誓言措辞，执行 `--set_oath "玩家原话"`。

原创誓言必须满足下方 §原创誓言规范。

---

## 寻源 (Seek the Source)

- **对象**：酿主——那个不断喷吐白息、控制圣水的存在
- **规模**：史诗誓言 / DC 18
- **内在张力**：你必须接近一个正在杀死所有人的东西——找到它可能意味着终结它，也可能意味着理解后的原谅
- **触发契机**：发现酿主可能是机器或活物后（`brewer_understanding` 已锁定）
- **世界突变**：flag — `source_understood`：酿主的秘密已被揭开，世界为之改变

## 归座 (Claim the Seat)

- **对象**：基座——云室深处的钢铁遗迹，据说还亮着灯
- **规模**：地区誓言 / DC 14
- **内在张力**：基座可能根本不是你记忆中的样子——那里的人可能不认识你，或者更糟：认识你
- **触发契机**：遇到基座流放者、发现基座信号、或 `plinth_rumor` 已锁定
- **世界突变**：flag — `seat_claimed`：基座承认了你的存在——或被永远拒绝

## 救渴 (Quench the Thirst)

- **对象**：圣水依赖——定居点每个人喉咙上的锁链
- **规模**：地区誓言 / DC 14
- **内在张力**：找到替代意味着摧毁现有的秩序——祭司会失去权力，人们会恐慌，有些人宁愿渴死也不信你
- **触发契机**：发现圣水的真相后（`holy_draught_effect` 已锁定）
- **世界突变**：flag — `thirst_broken`：至少一些人不再依赖圣水——祭司的权柄开始动摇

## 越墙 (Cross the Wall)

- **对象**：云室的边界——据说外面什么都没有，但没人活着回来证实
- **规模**：个人誓言 / DC 10
- **内在张力**：跨过去可能是自由，也可能是虚无——而且一旦跨过去，你关心的人还在墙这边
- **触发契机**：从灰质者长老口中听说"外面"、发现旧世界地图上云室之外的标记、或任何暗示边界之外有东西的线索
- **世界突变**：flag — `wall_crossed`：你是第一个回来的人——或者根本没回来

## 原创誓言规范

DM 在誓言选择步骤中即兴创建 2 个原创誓言。每次从以下三个维度各取一项，组合成誓言。两个誓言不得使用相同的维度组合。

| 维度 | 选项 |
|------|------|
| **对象层**（誓言指向谁/什么） | 一个具体的人 / 一个地点 / 一个被隐藏的真相 / 一个正在发生的过程 |
| **规模层**（决定 DC） | 个人誓言 DC 10（影响自己或一个人）/ 地区誓言 DC 14（影响干岸或某个群体）/ 史诗誓言 DC 18（影响世界的结构） |
| **张力层**（誓言内部的矛盾） | 你想要的和你必须付出的之间有冲突 / 完成誓言会伤害你在乎的人 / 誓言本身可能基于错误的前提 |

**约束**：
- 对象必须扎根于云室世界观——引用已有地点、NPC、或玩家已接触的真相
- 两个原创誓言不得指向同一对象层选项
- 规模层至少有一个为个人或地区（避免两个都是史诗）
- 张力必须具体——不是"可能付出代价"，而是"如果你要找到旧爱，就必须回到曾被宣告死亡的低地"
- 原创誓言的名称使用 2-3 字中文短语（如 `断瘾`、`寻弟`）
- 每个原创誓言必须附带一句话简述（与固定池格式一致）
- 玩家选定原创誓言后，DM 当场将誓言追加到本文件固定池下方，标注 `[来源：session_{日期}]`

### 原创誓言模板

DM 创作时填充以下字段：

```
## {誓言名}

- **对象**：{具体的人/地点/真相/过程}
- **规模**：{个人/地区/史诗} / DC {10/14/18}
- **内在张力**：{一句话写出矛盾——想要什么 vs 必须付出什么}
- **触发契机**：{基于玩家已接触的真相或已知世界元素}
- **世界突变**：flag — {key}: {一句话描述完成后的世界变化}
```
