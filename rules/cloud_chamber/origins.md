# 身份起点

以下三个为**固定池**。每次角色创建时，DM 从中随机抽 1 个，再即兴原创 2 个，合计 3 个作为 AskUserQuestion 选项——不标明哪个是固定的。

玩家选定后不可更改。结果写入 state.json 的 origin 字段。属性钟按所选起源的命令设置。

原创起源必须满足 §原创起源规范（见 rules.md §二）。

## 祭坛洗刷工 (The Scrubber)

- **key**: `scrubber`
- **大地点**：祭坛区
- **社会地位**：最底层
- **在乎的事物**：每天配给的那一小份口粮要带回去给妹妹；圣樽台阶第三级松动的石板下藏着一本旧世界的图册
- **初始已知真相**：圣水会腐蚀金属（物理特性）
- **初始危机**：目睹圣樽破碎，掌握了不该掌握的物质
- **属性倾向**：躯壳 3 / 清明 1 / 根系 2 / 胆识 2
- **特殊能力**：能凭气味判断圣水纯度
- **社会关系**：定居点贱民身份，祭司对你有天然优越感

```
python .claude/skills/rpg-dm/scripts/tools/state_mgr.py --set_clock 胆识 2
```

- **旧伤选项 (scar_options)**：
  1. "你妹妹越来越瘦了。每天省下的口粮不够，你看着她的手腕细得像枯枝。你不知道还能撑多久——但你不敢算。"
  2. "你曾经有一个同伴——另一个洗刷工。他比你更早发现圣水的秘密。一周后他被调去'禁地勤务'，再也没回来。你从未问过他去了哪里，因为你怕听到答案。"
  3. "那晚你在后殿听到了不该听到的东西——祭司们压低声音争论'库存'和'地下三层'。他们没看见你蜷在井廊拐角。但从那天起，你看每一个祭司都像在看一个知道你知道的人。"

- **执念选项 (drive_options)**：
  1. "你妹妹能活多久，取决于你在祭坛区能藏多久。每一天都是偷来的——你要让每一天都值得。"
  2. "你想知道圣水到底是什么。不是为了反抗——只是为了在下一次刷洗的时候，知道自己手上沾的是什么。"
  3. "那个人替你去了禁地。你在洗刷井廊的墙缝里刻了一个记号。你不会让那个记号白画。"

- **形貌选项 (appearance_options)**：
  1. "你的手指关节因常年浸泡圣水而粗糙发白——指节突出，皮肤像被腌过。手比脸老了十岁。"
  2. "你的肩膀微微前倾——不是天生，是常年在低矮井廊弯腰刷洗留下的。走路时习惯贴着墙根，从不走巷道正中。"
  3. "你有一双不属于这个阶层的眼睛——太安静，太专注。祭司从你身边走过时偶尔会觉得后颈发凉，但不会承认。"

- **初始物品 (starting_items)**：半块干饼、旧世界图册残页

## 远征队弃子 (The Straggler)

- **key**: `straggler`
- **大地点**：低地边界
- **社会地位**：中层，但已被宣告死亡
- **在乎的事物**：远征队里还有一个人没出来——你答应过要带他回去；口袋里有一块刻了名字的金属牌，那是你唯一没丢掉的东西
- **初始已知真相**：见过灰质者，知道低地真实生态
- **初始危机**：处于枯萎症早期，被定居点视为已死之人
- **属性倾向**：躯壳 2 / 清明 2 / 根系 1 / 胆识 3
- **特殊能力**：在低地的方向感和生存判定有利。获得永久标签【枯萎先兆】
- **社会关系**：定居点无法公开你的身份，你必须伪装

```
python .claude/skills/rpg-dm/scripts/tools/state_mgr.py --set_clock 胆识 3
```

- **旧伤选项 (scar_options)**：
  1. "火把光消失的方向——那是他们离开的方向。你记得每一张转过去的脸，尤其是那个最后回头看你的。他的表情不是愧疚，是松了一口气。"
  2. "你的眼睛开始发黄了。队长说那是枯萎症的第一个迹象。每次看向水里自己的倒影，你都比上一次更不像自己。你不知道还剩多少时间。"
  3. "远征队里还有一个人没出来。你答应过要带他回去。你口袋里有他的身份牌——你不敢看上面的名字，但每天都会摸一下确认它还在。"

- **执念选项 (drive_options)**：
  1. "那个人还在里面。你不知道他是死是活——但你知道如果自己不去确认，这辈子每次闭眼都会看到他的脸。"
  2. "他们宣告你死了。你要让他们知道他们错了——不是出于愤怒，只是你想活着走到一个能大声说出自己名字的地方。"
  3. "枯萎症没有已知的解药——但你在低地见过灰质者。他们活着。你想知道为什么。"

- **形貌选项 (appearance_options)**：
  1. "你眼白发黄——枯萎症的早期征兆。风吹日晒把你的皮肤磨成了粗陶的颜色。额角有一道旧伤，是第一天掉进嗜醇丛时划的。"
  2. "远征队的灰蓝色外套已经穿得认不出原色。左肩缝了三道粗针脚——你自己缝的，针法很糟。走起路来左脚微跛，你学会了不让人看出来。"
  3. "你比实际年龄老了不止十岁。白息把你的声带磨粗了，说话像喉咙里总含着一口沙。但你站得很直——那是一种你还没意识到自己还在坚持的骄傲。"

- **初始物品 (starting_items)**：圣水（半瓶）、金属身份牌

## 基座流放者 (The Plinth-Exile)

- **key**: `plinth_exile`
- **大地点**：禁地附近
- **社会地位**：外来者，被视为带来诅咒的怪物
- **在乎的事物**：你被流放前有人塞给你一张纸条，上面写着一个坐标和一句话——"到了那里，呼吸是免费的"；你想证明那个人没有说错
- **初始已知真相**：懂旧世界语言，能读懂生锈机器上的标识
- **初始危机**：地表氧气稀薄，持续承受适应性体质损耗
- **属性倾向**：躯壳 1 / 清明 3 / 根系 2 / 胆识 2
- **特殊能力**：面对旧世界设备时免除首次检定失败的最坏结果
- **社会关系**：没有任何定居点关系，从零建立

- **旧伤选项 (scar_options)**：
  1. "升降梯关上的时候很轻。没有人给你时间说什么——两个技术员架着你，第三个按了按钮。你甚至没来得及看最后一个走廊。然后地板开始上升。"
  2. "你被流放前有人在禁闭室的墙缝里塞了一张纸条。上面的字迹你认得——但你不确定那个人塞给你是因为想救你，还是因为不想欠你。"
  3. "地表空气里的每一口呼吸都在提醒你——你不属于这里。你的肺太小了，你的血太稠了。基座的人是对的：地面上没有人能活着。但你还在呼吸。"

- **执念选项 (drive_options)**：
  1. "纸条上写着一个坐标和一句话：'到了那里，呼吸是免费的'。你不确定这是真的还是一个陷阱——但你必须走到那里，因为你没有别的方向了。"
  2. "基座里的人不知道地面是什么。他们以为流放等于死亡。你要活下去——不是为了复仇，只是为了让他们有一天看到一个活着的地面人。"
  3. "你能读懂旧世界文字。那些生锈机器上的标识在别人眼里是花纹，在你眼里是句子。你想知道写这些句子的人后来去了哪里。"

- **形貌选项 (appearance_options)**：
  1. "你瘦得不像是从地下出来的人——地表氧气稀薄让你的胸腔长期处于轻微的缺氧状态。说话时偶尔会停顿半秒，像是要记起下一口气该怎么吸。"
  2. "你穿着基座的标准灰色连体服——已经磨破了肘部和膝盖。领口内侧缝着一个编号，那是你在基座的唯一身份。你没有拆掉它。"
  3. "你的眼睛对光太敏感了。地表散漫的日光让基座人无法适应，但你已经学会了眯眼看远处——那是你在禁闭室里养成的习惯，在黑暗中辨认墙上的刻痕。"

- **初始物品 (starting_items)**：旧世界设备、坐标纸条

## 守卫逃兵 (The Guard Deserter)

- **key**: `guard_deserter`
- **大地点**：祭坛区
- **社会地位**：前执法者，现为逃亡者
- **在乎的事物**：你逃跑那晚，有个和你一起值夜的新兵替你挡了追兵——你不知道他现在是死是活；你腰上还挂着他塞给你的半块干饼
- **初始已知真相**：曾见过不该存在的东西——祭坛后殿的某扇门后面，有什么在呼吸
- **初始危机**：正在被曾经的同袍追杀，他们说你擅离职守，但你知道真正的原因
- **属性倾向**：躯壳 3 / 清明 1 / 根系 2 / 胆识 2
- **特殊能力**：熟悉祭坛区的每一条巷子和巡逻路线，在祭坛区的潜行和逃脱判定有利
- **社会关系**：曾经的守卫同袍现在可能是追兵，也可能是装作不认识你的旧友

```
python .claude/skills/rpg-dm/scripts/tools/state_mgr.py --set_clock 胆识 2
```

- **旧伤选项 (scar_options)**：
  1. "祭坛后殿有一扇门。你值夜那晚听到门后面有什么在呼吸——不是人的呼吸，是更慢、更湿、更重的东西。你告诉了队长。第二天他派你去禁地巡逻。你知道那不是巧合。"
  2. "你逃跑那晚，有个和你一起值夜的新兵替你挡了追兵。他才来两个月——连你姓什么都不知道。你不知道他现在是死是活，但你能想象如果他活着，别人是怎么审他的。"
  3. "你曾是他们的执法者。你没收过配给、执行过流放、在众人面前把违反祭坛纪律的人拖走。那些脸你都记得。现在你也成了需要躲藏的人。"

- **执念选项 (drive_options)**：
  1. "那个新兵替你挡了追兵。你不知道他是死是活——但你需要知道。如果他还活着，你要找到他。如果他死了，你要让做决定的人付出代价。"
  2. "后殿那扇门后面的东西——你不知道那是什么，但你知道大祭司知道。你要让他告诉你。不是为了公道，只是为了不再在夜里听到那种呼吸声。"
  3. "你曾是他们的剑。现在你要让他们看到——这把剑砍向哪里，应该由握剑的人自己决定。"

- **形貌选项 (appearance_options)**：
  1. "你身上还有守卫的痕迹——站得太直，眼神习惯性地扫视每个人的腰间和袖口。即使穿着破斗篷，走路的节奏仍然是巡逻步——慢、稳、随时可以加速。"
  2. "你的手腕和掌心有老茧——不是劳动的，是握兵器握出来的。颧骨很高，脸颊因为最近吃得太少而微微凹陷。下巴的胡茬长了三天，你还没找到干净的水可以剃。"
  3. "你的背上有一道从肩膀划到肋骨的旧伤——不是追捕时受的，是更早的。你不谈论它。别人问起时，你的右手会下意识地移到腰侧——那个曾经挂着武器的地方。"

- **初始物品 (starting_items)**：半块干饼、守卫斗篷
